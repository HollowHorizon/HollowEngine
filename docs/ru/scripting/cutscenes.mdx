<center><h1>Катсцены</h1></center>

*Создание камерных сцен в редакторе и запуск из скрипта.*

---

## Создание катсцены

1. Открой **Windows > Cutscenes** и создай новую катсцену.
2. Добавь ключевые кадры на дорожки позиции камеры, поворота и FOV. При добавлении ключа редактор запоминает текущую позу камеры.
3. Задай длительность и проверь сцену в предпросмотре таймлайна.
4. Сохрани катсцену. Например, `intro` будет записана в `hollowengine/cutscenes/intro.dat`.
5. Запусти её для игрока из серверного скрипта.

Дорожки камеры вычисляются на клиенте получившего игрока. Состояние мира игрока не меняется: пока активна катсцена, движок управляет только камерой, HUD и отрисовкой руки.

## Запуск и остановка

```kotlin
player.playCutscene("intro")

// Повторяется, пока её не остановят.
player.playCutscene("ambient_pan", loop = true)

player.stopCutscene()
```

`playCutscene` заменяет текущую катсцену игрока. Используй путь относительно `hollowengine/cutscenes`; расширение `.dat` писать необязательно. `stopCutscene()` сразу возвращает обычную игровую камеру.

## Простой триггер сцены

```kotlin
@State
suspend fun onInteract(player: ServerPlayer) {
    player.playCutscene("chapter_1/arrival")
    player.send("Добро пожаловать в долину.")
}
```

Для зацикленной камеры в зоне запусти её при входе игрока и вызови `stopCutscene()` при выходе. Не запускай одну и ту же катсцену каждый тик: достаточно одного вызова.
