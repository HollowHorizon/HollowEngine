<center><h1>Введение в скриптинг</h1></center>

Скрипты HollowEngine пишутся на Kotlin и размещаются в `hollowengine/scripts`. Их можно редактировать во внешнем редакторе, но встроенная IDE мода уже предоставляет подсветку, диагностику и автодополнение.

## Типы скриптов

- [Простой](/docs/hollowengine/scripting/simple) (`.kts`): одноразовый запуск или общий код, например функции и утилиты.
- [Перезагружаемый](/docs/hollowengine/scripting/reload) (`.reload.kts`): обработчики игровых событий. Запускается при старте сервера и перезагрузке ресурсов (`/reload`).
- [Node](/docs/hollowengine/scripting/node) (`.node.kts`): coroutine-обработчики, которые можно прикреплять к серверу или сущности. Подходят для периодических действий, собственных данных, событий сущности и состояний.
- [UI](/docs/hollowengine/ui) (`.ui.kts`): клиентские объявления экранов и HUD-оверлеев. При перезагрузке ресурсов они компилируются заново. Серверные скрипты открывают объявления по id и обновляют их состояние через `UiSession`.

Типы скриптов отличаются базовым классом, доступным API, стороной выполнения и условиями запуска. Для UI-скриптов на клиенте нужен аддон Kotlin scripting compiler. Скрипты можно перекомпилировать и обновлять без перезахода в игру или мир.
