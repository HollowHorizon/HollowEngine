<center><h1>Миры</h1></center>

*Действия связанные с измерениями.*

![Level Events](/docs/title-missing.webp)

## Сохранение

```kotlin
@SubscribeEvent
fun onSave(event: LevelEvent.Save) {
    val entity = event.entity
}
```

- `event.level` (Level) - сохраняемое измерение.

## Загрузка

```kotlin
@SubscribeEvent
fun onSave(event: LevelEvent.Load) {
    val entity = event.entity
}
```

- `event.level` (Level) - загружаемое измерение.
