<center><h1>Стили UI</h1></center>

Этот раздел посвящён переиспользуемому оформлению скриптовых интерфейсов. Структура и поведение UI описаны в разделе [UI-скрипты](/docs/hollowengine/scripting/ui), а HSS-файлы задают темы, состояния, переходы и анимации отдельно от Kotlin-кода.

## Где описывать стиль

Используйте HSS для общих статических правил: цветов, отступов, текстур, псевдосостояний, переходов и именованных анимаций. Узлы выбираются по `id`, тегам, типу и состоянию, после чего таблица стилей подключается из UI-скрипта через `Modifier.style(...)`.

Kotlin-модификаторы подходят для значений, которые зависят от состояния скрипта или относятся только к одному узлу. Оба варианта используют одинаковые свойства layout и рендеринга, поэтому локальный модификатор может дополнить или переопределить правило HSS без копирования всего стиля.

## Страницы раздела

- [HSS-файлы](/docs/hollowengine/scripting/ui/styles/hss-files): селекторы, значения, свойства, псевдосостояния, поддержка редактора и полный справочник.
- [Анимации и трансформации](/docs/hollowengine/scripting/ui/styles/animations): переходы, keyframes, трансформации и фильтры.
- [Kotlin-модификаторы](/docs/hollowengine/scripting/ui/modifiers): вычисляемые и локальные стили внутри `.ui.kts`.
