## Saving

```kotlin
@SubscribeEvent
fun onSave(event: LevelEvent.Save) {
    val entity = event.entity
}
```

- `event.level` (Level) - the dimension being saved.

## Loading

```kotlin
@SubscribeEvent
fun onSave(event: LevelEvent.Load) {
    val entity = event.entity
}
```

- `event.level` (Level) - the dimension being loaded.
