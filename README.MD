## Introduction

HollowEngine is a powerful engine for Minecraft content creation. It provides an easy way to create scripts for creating NPCs, Events, Game modification and some other useful tools.

## Features

### Content

- [x] Integrated development environment with autocomplete and code analysis support.
- [x] Kotlin Scripting for server, npcs and UI.

### NPCs

- [x] Basic NPC creation.
- [x] Changing model, textures, animations, adding sub-models. With glTF support.
- [x] Actions for NPCs: move & look control, teleport, play animations, item requests & drops.
- [x] NPC Component System.
- [ ] NPC Trading.
- [ ] NPC Quests.

### Game modifications

- [x] Events handling.
- [ ] Recipe Changing.
- [ ] Adding new blocks & items.
- [ ] Adding new structures.
- [ ] Biome modifications.
- [ ] Mobs modifications.
