## Introduction

HollowEngine is a powerful engine for Minecraft content creation. It provides an easy way to create scripts for creating NPCs, Events, Game modification and some other useful tools.

## Features

### Contents
- [x] [2.0] Integrated development environment with autocomplete and code analysis support.
- [ ] [2.0] Episode editor for creating animated dialogues and some scripting.
- [ ] [2.0] Cutscene editor based on keyframes & tracks for managing camera, mobs, time, blocks, etc.
- [ ] [2.0] Node-based story creation with triggers, conditions, loops, etc.   

### NPCs
- [x] Basic NPC creation.
- [x] Changing model, textures, animations, adding sub-models. With glTF support.
- [x] Actions for NPCs: move & look control, teleport, play animations, item requests & drops.
- [x] [2.0] NPC Trading.
- [ ] [2.0] NPC Quests.
- [ ] [2.0] NPC Behavior scripting.

### Game modifications
- [x] Recipe Changing.
- [x] Adding new blocks & items.
- [x] Adding new structures.
- [ ] [2.0] Biome modifications.
- [ ] [2.0] Mobs modifications.
